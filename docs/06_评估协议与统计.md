# 评估协议与统计

## 1. 选模和最终测试

- 训练集：更新参数；
- 验证集：早停、损失权重和模型选择；
- 测试集：配置冻结后只运行最终评估。

任何一次查看测试结果后继续调模型，都应视为测试集信息泄漏。

## 2. 主指标

### 与原论文直接对齐

- `mae_normalized`：归一化 `[0,1]` 相位 MAE；
- `fidelity_2d_correlation`：二维 Pearson 相关系数。

### 光学和图像指标

- `mae_rad`、`rmse_rad`；
- `circular_mae_rad`；
- `aligned_mae_rad`：去除每幅图的全局圆周相位偏置后误差；
- `SSIM`；
- `PSNR`；
- `gradient_mae_rad_per_pixel`；
- residual standard deviation。

原始公开标签位于 `[0,π]` 且背景固定，**raw MAE 必须作为主指标**。aligned 指标只能作为辅助分析，不能替代 raw 指标。

## 3. 不确定度

主模型输出：

- aleatoric：像素级 Laplace scale；
- epistemic：MC Dropout 多次前向标准差；
- total：二者平方和开根号。

报告 risk–coverage：按不确定度从低到高保留 100%、90%、80%、70%、50%、30% 样本，观察保留样本 MAE 是否下降。

## 4. 分域和跨域

必须单独报告：

```text
digits test
fashion test
mixed test
digits train → fashion test
fashion train → digits test
```

Fashion 结构更复杂，混合平均值可能掩盖某一域退化。

## 5. 少样本

建议：

```text
每域 50 / 200 / 1000 / 5000 / 全量训练样本
```

所有少样本实验共用同一 val/test。训练子集应嵌套或固定随机种子，避免不同 shots 之间样本组成完全不同。

## 6. 传感器扰动

测试：

- Gaussian noise；
- gain；
- background；
- blur；
- camera shift；
- saturation；
- dead pixels。

这些是合成的测量扰动，只能证明算法对指定扰动的稳定性，不能等价为跨光纤、跨波长或跨实验装置泛化。

## 7. 延迟

报告：

- GPU 型号；
- PyTorch/CUDA；
- batch size；
- warmup 数；
- 单样本和单 batch 延迟；
- 是否包含数据读取；
- 扩散采样步数。

单次网络应报告纯前向和端到端两种延迟；本工程的 `benchmark_latency.py` 测纯网络前向。

## 8. 统计

- 至少三个独立训练随机种子；
- 每个种子保留逐样本 CSV；
- 每个种子内部报告 bootstrap 95% CI；
- 模型比较使用相同测试样本上的配对统计；
- 不要只展示最好 seed。
