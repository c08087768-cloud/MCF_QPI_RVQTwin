# 研究定位与相关工作

## 1. 已有相近研究

### 1.1 FAST：单幅远场散斑的模型迭代相位恢复

2022 年的超薄无透镜多芯光纤 QPI 工作通过单幅远场散斑恢复入射复光场，并可数字重聚焦和重建多层样品。它证明了物理问题可解，但需要系统校准和迭代，计算负担较高。

### 1.2 MCF-QPI 原始公开数据论文

2024 年 Optics Letters 工作建立自动实验采集系统，公开 50,176 对散斑—相位图，并用 U-Net/ResNet 混合网络直接回归相位。论文报告约 5.5 ms 推理、181 fps，以及基于二维相关系数的平均重建 fidelity 最高约 0.998。

### 1.3 SpecDiffusion

SpecDiffusion 使用 speckle-conditioned diffusion 从 MCF 散斑恢复更复杂的显微相位结构。其论文使用作者自建的 100,000 对实验数据，并包含少量组织迁移实验。它说明“扩散模型用于 MCF 相位恢复”已经有人做过，因此本项目不能把“首次把扩散/VQ 用到相位恢复”作为未经检索支持的绝对首创声明。

### 1.4 物理模型驱动网络

2025 年已有 lensless fiber endomicroscopic phase imaging 的物理模型驱动网络，利用角谱传播和多距离散斑约束。公开 MCF-QPI 数据只有配对的单平面散斑与相位，并不包含该方法所需的多距离采集和系统标定，因此不能直接用同一数据复现其物理约束。

### 1.5 其他相关方向

多模/多芯光纤领域还有自监督动态学习、传输矩阵、物理信息扩散等方法，但它们的任务常是强度图像传输、动态 MMF 重建或已知 TM 条件下的成像，不等于本公开数据的二维相位回归任务。

## 2. 本项目应避免的弱创新

以下单独一项通常不足以形成稳健创新：

- 把 U-Net 换成普通 VQ-VAE；
- 在损失中简单增加 SSIM；
- 增加一个 Transformer 模块但不做跨域/少样本分析；
- 把数据驱动 forward network 命名为 PINN；
- 只在作者极小测试集上报告一个更高的相关系数。

## 3. 推荐创新组合

本项目采用 `MCF-RVQTwin`：

1. **双域测量编码。**空间域分支学习散斑局部统计，Fourier 对数幅度分支学习全局频谱，门控融合后得到潜状态。
2. **Residual VQ 相位先验。**先只用训练标签学习离散相位字典，再把散斑潜状态投影到码本；小连续残差补偿硬量化细节损失。
3. **经验测量闭环。**真实配对训练 phase→speckle 代理；只有其独立验证性能合格时，才冻结用于 cycle consistency。
4. **校准不确定度。**输出像素 Laplace scale，并通过 MC Dropout 获得 epistemic uncertainty，报告 risk–coverage 曲线。
5. **数据效率和泛化。**官方 split、严格哈希 split、digits↔fashion 跨域、50/200/1000 样本、传感器扰动和三随机种子。

## 4. 可形成的论文问题

主问题不是“能否从散斑恢复相位”，因为原论文已经回答，而是：

> 在只使用同一公开真实 MCF-QPI 数据的条件下，离散相位先验、双域测量特征和经验测量闭环能否提升低数据、跨内容域和传感器扰动下的相位恢复，并提供可校准的失败告警？

这比只追求官方测试集上的平均相关系数更有工程意义。
