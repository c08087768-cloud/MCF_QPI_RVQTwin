# MCF-QPI 实验结果分析报告

> 数据来源：`outputs/research/` + `outputs/ablations/`，2026-08-24。
> 主流程模型为**三随机种子**（42/123/2026）均值±标准差；消融与扩散为 seed=42 单种子（实验设计上仅做单种子对比）。
> 测试集：174 样本（digits test 78 + fashion test 96）。指标：MAE(rad)、二维相关系数（2D corr，即原论文 fidelity）、SSIM、PSNR(dB)。

---

## 0. 参与对比的模型（先认识它们）

全文反复出现一条排位 `paper_style_resunet > baseline_resunet > proposed_rvqtwin(及四项消融) >> diffusion`。在进入结果前，先说明每个名字指的是什么、由什么构成、在对比中扮演什么角色。

### 0.1 paper_style_resunet（原论文训练策略风格复现）

- **代码**：`src/mcfqpi/models/resunet.py` 的 `ResUNetPhase`；配置 `configs/research/paper_style_resunet.yaml`。
- **是什么**：接近原论文公开训练策略的 ResUNet 复现——三次下采样 + 三次上采样 + 残差块 + skip connection。输出归一化相位 `[0,1]` 与 `log_scale`（Laplace 像素尺度，用于异方差不确定度）。
- **训练**：40 epoch、无早停（`early_stopping_patience: 0`）、step-wise scheduler（`step_size: 20000`）。参数量 6.26M。
- **角色**：与原文可比口径的参照点，用来对齐"原论文做法"这一档。

### 0.2 baseline_resunet（强监督基线）

- **代码**：同一个 `ResUNetPhase`；配置 `configs/research/baseline_resunet.yaml`。
- **是什么**：结构/参数量与 paper_style **完全相同**（6.26M），区别只在训练配置——60 epoch + `early_stopping_patience: 12`、更强的监督损失组合。
- **角色**：本工程的"干净强监督基线"，是判断其他方法是否真有增益的基准线。

### 0.3 proposed_rvqtwin（主模型，双域 RVQ-Twin）

- **代码**：`src/mcfqpi/models/dual_domain_rvq_twin.py` 的 `DualDomainRVQTwin`；配置 `configs/research/proposed_rvqtwin.yaml`。
- **是什么**：本工程的核心提案，由四个部件拼成（对应 `docs/04`）：
  1. **双域编码**：空间域分支（学散斑颗粒/局部对比度）+ 频域分支（对输入做 `FFT → log(1+|F|) → 归一化`，学全局频谱），经门控融合 `z = g⊙z_s + (1-g)⊙z_f + R([z_s,z_f])`；
  2. **Residual VQ 相位先验**：把散斑潜变量投影到预训练的相位码本（`phase_rvqvae` 冻结码本），再做受限连续残差 `+ α·tanh(R(z))`；
  3. **经验 forward twin**：可选的 phase→speckle 前向代理，用于 cycle loss；
  4. **不确定度头**：输出像素级异方差。
- **训练**：80 epoch、`early_stopping_patience: 15`，参数量 3.36M（反而比 ResUNet 少，因为共享了预训练先验）。依赖两个预训练产物：`phase_rvqvae_seed42/best.pt`（相位先验）与 `forward_twin_seed42/best.pt`（前向代理）。
- **角色**：论文的"新方法"主角——但结果是负的（见 §1、§4）。

### 0.4 四项消融（proposed 的组件开关）

都是 `DualDomainRVQTwin` 的变体，通过配置开关某个组件，用于定位"复杂主干输在哪"。配置在 `configs/ablations/`，seed=42 单种子。

| 消融                   | 关掉什么                                          | 保留什么          | 想回答的问题      |
| -------------------- | --------------------------------------------- | ------------- | ----------- |
| `no_forward_twin`    | forward twin + cycle loss（权重全 0）              | 双域 + RVQ 全部先验 | cycle 是否在干扰 |
| `dual_continuous`    | 离散量化（`use_quantization: false`，VQ/token 权重 0） | 双域 + 纯连续潜空间   | 离散码本是否有用    |
| `spatial_only_rvq`   | 频域分支                                          | 只空间域 + RVQ    | 频域分支是否必要    |
| `frequency_only_rvq` | 空间域分支                                         | 只频域 + RVQ     | 空间域是否必要     |

### 0.5 diffusion（条件扩散生成式基线）

- **代码**：`src/mcfqpi/models/diffusion.py` 的 `ConditionalDenoiser` + `GaussianDiffusion`；配置 `configs/research/diffusion_baseline.yaml`。
- **是什么**：speckle-conditioned 的 DDPM 训练 + DDIM 推理。训练 200 epoch（`timesteps: 1000`），推理在 25/50/100 三个采样步下分别评估。参数量 4.26M。
- **角色**：回答"生成式迭代方法是否在复杂 Fashion 结构上更准、速度代价多大"（`docs/04 §7`）。结果全面垫底（见 §3.3）。

## 1. 核心结论（先看这个）

**模型越简单越准。** 在 MCF-QPI 真实散斑→相位任务上，强监督 ResUNet 全面胜过复杂主干（双域 RVQ-Twin）和生成式（条件扩散），且该结论在三随机种子下稳定（标准差极小）。

排位：

```
paper_style_resunet > baseline_resunet > proposed_rvqtwin(及四项消融) >> diffusion
       MAE 0.0265        0.0427          0.0497                     0.154
```

主模型（proposed）在所有指标上均**输给**两个 ResUNet 基线，且无论怎么消融都无法翻盘。这是一个需要正视的**负结果**——但消融矩阵清晰解释了原因，并产出了若干有价值的单点发现（见 §4）。

## 3. 消融矩阵（seed=42，单种子）

### 3.1 双域 RVQ 主干内部消融（验证各组件贡献）

| 消融                 | 关掉什么           | MAE(rad)↓ | 2D相关↑  | SSIM↑  | PSNR↑ | phase_l1末 |
| ------------------ | -------------- | --------- | ------ | ------ | ----- | --------- |
| proposed（完整）       | —              | 0.0497    | 0.9895 | 0.9484 | 29.02 | 0.0180    |
| no_forward_twin    | cycle loss     | 0.0493    | 0.9896 | 0.9487 | 29.05 | 0.0179    |
| dual_continuous    | 离散量化(VQ/token) | 0.0499    | 0.9890 | 0.9461 | 28.86 | 0.0180    |
| spatial_only_rvq   | 频域分支           | 0.0519    | 0.9883 | 0.9449 | 28.51 | 0.0194    |
| frequency_only_rvq | 空间域分支          | 0.0849    | 0.9704 | 0.8889 | 24.32 | 0.0310    |


### 3.2 消融读出的四个事实

1. **cycle loss 无增益**：`no_forward_twin`(0.0493) ≈ proposed(0.0497)，关掉 cycle 不变差。结合 §5.1 forward twin 独立质量极好（PSNR 38dB），说明**前向代理虽准，但 cycle 约束没转化为逆模型增益**——这是可写的负发现。

2. **RVQ 离散量化无增益**：`dual_continuous`(0.0499) ≈ proposed(0.0497)，去掉离散码本换成纯连续潜空间，指标不变。**相位先验的离散码本约束没有帮上忙**，与 `docs/04 §2` "若 perplexity 低先降码本规模" 的预期一致——先验约束在此任务过强。

3. **频域分支单独崩盘**：`frequency_only`(0.0849) 是 `spatial_only`(0.0519) 的 1.6 倍，SSIM 从 0.945 跌到 0.889。**散斑的局部结构（空间域）是相位恢复的主信号，全局频谱单干远不够**。

4. **双域融合边际有效但不足以反超**：proposed(双域 0.0497) < spatial_only(0.0519)，频域对双域有约 4% 的边际改进——方向对，但幅度太小，无法让复杂主干超过简单 ResUNet。

### 3.3 生成式基线（扩散，seed=42）

| 采样步 | MAE(rad)↓ | 2D相关↑ | SSIM↑ | PSNR↑ |
|--------|----------|---------|-------|-------|
| 25 steps | 0.1585 | 0.9579 | 0.4960 | 22.15 |
| 50 steps | 0.1541 | 0.9571 | 0.5082 | 22.10 |
| 100 steps | 0.1596 | 0.9561 | 0.4772 | 21.93 |

**条件扩散全面垫底**：MAE 是 baseline 的 3.6 倍，SSIM 仅 0.50（判别式 0.95+），且**采样步数 25/50/100 几乎无差异**——瓶颈不在采样而在模型本身。直接回答 `docs/04 §7` 的研究问题：**生成式迭代方法在本任务上既不更准也不更快**（每次推理要迭代数十步去噪，延迟代价巨大，见 §5.2）。这是干净的负结果，可作为论文中"生成式 vs 判别式"对比的支撑。

## 4. 根因分析：为什么复杂主干反而更差

对比收敛后的相位 L1（相位精度的最直接度量）：

| 模型 | phase_l1 收敛值 | 说明 |
|------|----------------|------|
| baseline_resunet | **0.0140** | 目标单一（phase+grad+ssim+pearson+nll） |
| proposed_rvqtwin | 0.0180（差 29%） | 8+ 项损失，先验正则稀释优化 |

**根因**：proposed 的总损失含 VQ/token/latent/residual/cycle 等多项正则，`token` 项全程维持在 4.5 量级（远大于 phase_l1 的 0.018），把优化方向从"相位准"拉向"码本对齐"。消融证明这不是单一项的锅（关 cycle、关 VQ 都不变好），而是**整套复杂先验约束整体上限制了逆模型的表达**。这与 `docs/04 §6` 警告"不要一次把所有权重设得很大"一致——本项目当前权重配置（token 0.15、latent 0.10）对该任务偏大。

### 4.1 上游根因：相位先验码本本身塌缩

除了主网络损失权重问题，还有一层**上游根因**：proposed 挂载的相位先验码本（阶段一 Phase-RVQ-VAE 产出）本身不健康。实测码本统计（seed42）：

| 码本级   | 死码比例                     | 归一化 perplexity | 判读                             |
| ----- | ------------------------ | -------------- | ------------------------------ |
| 第 1 级 | **59.4%**（256 个里 152 个废） | **0.171**      | 严重 collapse，只靠 ~44 个码字表征相位主体结构 |
| 第 2 级 | 0%                       | 0.416          | 健康                             |

归一化 perplexity 范围 [0,1]，0.171 意味着第一级码本利用率极低。**主网络挂载了一个"主体结构塌缩"的先验，离散约束不可靠**——这解释了为何 `dual_continuous` 消融（关掉量化）指标不变：码本本身就没提供有效先验，关不关都一样。这不是主网络调参能救的，需重训先验（降第一级码本规模 / 降 VQ 权重 / EMA 更新码本，详见 `docs/15` §1.1）。

## 5. 有效的单点贡献（论文可保留）

尽管主模型未胜出，以下几项工作独立有效，可单独成贡献：

### 5.1 经验 forward twin（前向代理）

| 指标（3种子 mean±std） | 值 |
|----------------------|-----|
| PSNR | 38.42±0.02 dB |
| pearson_r | 0.9956±0.0000 |
| MAE | 0.0082±0.0000 |

**由真实配对数据学习的 phase→speckle 前向代理质量优秀且三种子极稳定**。它不是 PINN/传输矩阵，而是数据驱动统计代理（`docs/04 §5` 已明确边界）。虽未给逆模型带来 cycle 增益，但其本身作为"可微前向一致性约束"的可行性已验证，可作为方法贡献点之一。

### 5.2 延迟评估（proposed, seed42, RTX 3090 Ti）

| batch | ms/batch | ms/样本 |
|-------|---------|---------|
| 1 | 2.71 | 2.71 |
| 8 | 8.27 | 1.03 |
| 32 | 29.40 | 0.92 |

纯模型前向（不含数据读取/相机曝光/主机→GPU 传输）。batch=32 时 0.92 ms/样本，满足实时性。**扩散基线的延迟代价**（每次推理迭代 25–100 步去噪）可据此估算为判别式的数十倍——支撑 §3.3 "生成式不更快"的结论。

### 5.3 鲁棒性评估（proposed, seed42, 8 种传感器扰动）

| 扰动 | MAE(rad) | 相对 clean |
|------|----------|-----------|
| clean | 0.0497 | — |
| gaussian_noise σ=0.02 | 0.0601 | +21% |
| gaussian_noise σ=0.05 | 0.1875 | **+278%** |
| gain 0.2 | 0.0499 | +0.5% |
| background 0.05 | 0.0499 | +0.5% |
| blur 3 | 0.0589 | +19% |
| shift 2px | 0.0829 | **+67%** |
| saturation 0.25 | 0.0493 | -0.7% |
| dead_pixels 0.01 | 0.0558 | +12% |

**读出**：模型对乘性扰动（gain/saturation）和背景几乎免疫，对**加性噪声和位移极敏感**——σ=0.05 噪声使误差涨 3.7 倍，2px 平移涨 67%。这对部署有明确指导：采集端需重点控噪与对齐。这是 `docs/13 Test-6` 的完整产出，独立于主模型胜负，是有价值的工程贡献。

### 5.4 跨域评估（proposed, seed42）

| 方向 | MAE(rad) | 2D相关 |
|------|----------|--------|
| digits→fashion 测试 | 0.0320 | 0.9942 |
| fashion→digits 测试 | 0.0640 | 0.9859 |

digits 训练迁移到 fashion 比反向更好，说明 digits 结构更通用、fashion 更难。这是 `docs/13 Test-4` 的产出，验证了模型的域迁移能力边界。

## 6. 论文叙事建议

数据足够支撑一篇诚实且有贡献的论文。三条可选路线，从"最省力且最稳"到"最进取但风险最高"排列如下。

### 路线 A：诚实负结果为主线（推荐）

**定位**：把"复杂方法为何在真实 MCF-QPI 上不如简单基线"当作核心科学问题来回答，负结果本身就是贡献。

**具体做法**：
1. 主表如实排四档：paper_style > baseline > proposed > diffusion，并给出三随机种子的 mean±std（§2 已就绪）。
2. 用消融矩阵（§3）系统拆解"复杂主干输在哪"——cycle 无增益、RVQ 离散量化无增益、频域单干崩盘、双域融合边际有效但不足以反超。这四点构成论文的分析章节主体。
3. 把 §5 的四项有效单点（forward twin 38dB、鲁棒性 8 扰动、跨域、延迟）作为独立贡献，不与主模型胜负绑定。
4. 叙事主线一句话："系统对比判别式（简单/复杂）与生成式方法在真实多芯光纤散斑相位恢复上的表现；发现强监督 ResUNet 最优，双域 RVQ 先验未带来增益，条件扩散既慢又差；并从消融与鲁棒性角度给出机制解释。"

**优势**：零额外 GPU 成本（数据已全部到位）；诚实、经得起审稿；分析深度（消融+鲁棒性+跨域）足以撑起工作量。
**劣势/风险**：主模型（proposed）是负结果，若投稿渠道偏好"方法必须 SOTA"，可能不被待见；需要把"分析贡献"写得足够扎实才能立住。
**工作量**：仅剩写作，无新增实验。
**适用**：目标期刊/会议接受系统性实证研究或负结果；或当前阶段想把现有结果固化为完整论文。

### 路线 B：在 val 集上调 proposed，冲击反超（进取，风险高）

**定位**：认为 proposed 结构理论上应更强，只是先验权重配置不当，通过规范化调参把主模型救回来。

**具体做法**（全程只用 val 集选参，test 只在最后跑一次）：
1. 削弱先验正则，把优化方向拉回"相位准"：`loss.token 0.15→0.05`、`latent 0.10→0.03`、`vq 0.05→0.02`。
2. 放宽连续残差表达，弥补量化丢失的细节：`residual_scale 0.15→0.3`。
3. 提升编码器容量：`base_channels 32→48`（若显存允许）。
4. 每组改动做单因子消融，val 上显著改善才保留；最终冻结后只跑一次 test。

**优势**：若能反超，proposed 的"双域+RVQ 先验"就成了正贡献，论文卖点更强。
**劣势/风险**：§3 已证明关 cycle、关 VQ 都不变好，说明瓶颈是整套复杂架构而非单一权重——**调参大概率也救不回**；且 §4 显示 token 项 4.5 量级远大于 phase_l1 的 0.018，即使调小也未必打破"先验约束压制表达"的格局。
**工作量**：约 +2~3 天 GPU（多组调参 + 每个候选跑 80 epoch）。
**适用**：愿意承担"调了也白调"的时间成本，且投稿方明确要求方法 SOTA 的场景。**注意**：一旦开始调参，必须严守 val/test 隔离（`START_HERE §5`），否则结果作废。

### 路线 C：换主线，把强基线 + 评估协议做成贡献

**定位**：接受"本任务上简单判别式模型就是最优"这一事实，把论文重心从"新网络结构"转移到"可靠基线 + 系统评估协议 + 可复用前向代理"。

**具体做法**：
1. 主线改为 baseline_resunet（强监督 + 不确定度 + 鲁棒性评估），proposed 与 diffusion 降为对照项。
2. forward twin（§5.1，PSNR 38dB、三种子极稳定）作为独立方法贡献——它是"由真实配对数据学习的可微前向一致性约束"，可用于未来的闭环/物理一致性正则。
3. 把 `docs/13` 的 8 套评估协议（分域/哈希 split/跨域/少样本/鲁棒性/选择性预测/延迟）包装成可复用的基准（benchmark）贡献。
4. 叙事："提出一个面向真实 MCF-QPI 的可复现评估基准，并验证强监督 ResUNet 为当前最优判别式方案；同时给出经验前向代理作为物理一致性的可微工具。"

**优势**：规避负结果；鲁棒性/跨域/延迟/协议这些工作本身就扎实，且不依赖"谁赢"；forward twin 是干净的独立贡献。
**劣势/风险**：偏离了 `START_HERE §3` 最初的"双域 RVQ-Twin"方法野心，相当于承认原主线不成立；"基准"类论文对协议的系统性和可复现性要求更高。
**工作量**：写作为主，可选补 baseline 的鲁棒性/跨域/延迟（当前这三套只跑了 proposed，若换主线需补 baseline 版本，约 +0.5 天 GPU）。
**适用**：更看重"诚实 + 可复现 + 有工程价值"而非"方法 SOTA"的投稿方向。

### 三路线对比速览

| 维度 | A（负结果主线） | B（调参反超） | C（换主线） |
|------|----------------|--------------|------------|
| 核心卖点 | 消融+鲁棒性分析 | 双域 RVQ 反超 | 基准+前向代理 |
| 额外 GPU 成本 | 0 | +2~3 天 | +0.5 天（可选） |
| 风险 | 低 | **高**（大概率白调） | 中（偏离原野心） |
| 诚实度 | 高 | 中（若成功则高） | 高 |
| 建议 | **首选** | 慎选 | 备选，与 A 可组合 |

**不建议**：为让 proposed 反超 baseline 而在 test 上反复试配置——违反数据隔离原则，且消融已定性此路不通。路线 A 与 C 可部分组合（A 的分析深度 + C 的 forward twin 独立贡献），这是性价比最高的方向。
