# 网络设计与损失函数

## 1. 基线：ResUNet

`ResUNetPhase` 使用三次下采样、三次上采样、残差块和 skip connection，接近原论文的 U-Net/ResNet 思路。输出：

```text
phase：归一化相位 [0,1]
log_scale：Laplace 像素尺度，用于异方差不确定度
```

必须先得到可靠基线，再讨论主模型贡献。

## 2. Phase-RVQ-VAE

只用训练集相位标签预训练：

```text
phase → convolutional encoder → residual vector quantizers → decoder → phase
```

Residual VQ 使用多个码本逐级量化残差：

\[
z_q=\sum_{q=1}^{Q} e_q(k_q).
\]

建议默认：

- latent channels：64；
- 3 次下采样；
- 2 个码本；
- 每个码本 256 个向量；
- commitment beta：0.25。

需要监控各码本 perplexity 和死码比例。若 perplexity 很低，先降低码本规模或 VQ 权重，而不是继续增大网络。

## 3. 双域散斑编码器

### 空间域分支

学习散斑颗粒、局部对比度和位置相关特征。

### 频域分支

对输入计算：

\[
F=\operatorname{Norm}\{\log(1+|\operatorname{FFT2}(I)|)\}.
\]

学习全局频谱和跨区域关系。

### 门控融合

\[
z=g\odot z_s+(1-g)\odot z_f+R([z_s,z_f]).
\]

网络可以按空间位置选择空间域或频域信息。

## 4. RVQ 投影和连续残差

散斑潜变量先投影到预训练相位码本，再加受限连续残差：

\[
z_{final}=Q_{RVQ}(z_{speckle})+\alpha\tanh(R(z_{speckle})).
\]

离散码提供结构先验，连续支路保留硬量化遗漏的细节。消融必须比较：

- 无 VQ；
- 单码本；
- 双码本；
- 无连续残差；
- 不同 residual scale。

## 5. 经验 forward twin

训练：

```text
真实 phase → forward twin → 预测归一化 speckle
```

主网络中可增加：

\[
\mathcal L_{cycle}=\|F_{emp}(\hat\phi)-I\|_1+\lambda_f\mathcal L_{spectrum}.
\]

重要限制：它是当前数据采集系统的经验代理，不是解析角谱模型、PINN 或实测 transmission matrix。若验证集前向质量差、或 cycle 消融无提升，必须关闭。

## 6. 总损失

\[
\begin{aligned}
\mathcal L={}&
\lambda_1\mathcal L_{MAE}
+\lambda_g\mathcal L_{grad}
+\lambda_s\mathcal L_{SSIM}
+\lambda_r(1-\rho)\\
&+\lambda_n\mathcal L_{Laplace}
+\lambda_t\mathcal L_{token}
+\lambda_z\mathcal L_{latent}
+\lambda_v\mathcal L_{VQ}\\
&+\lambda_c\mathcal L_{cycle}
+\lambda_{res}\|z_{res}\|_1.
\end{aligned}
\]

不要一次把所有权重设得很大。推荐顺序：

1. 先训练 `MAE + gradient + SSIM`；
2. 再加 token/latent/VQ；
3. 最后小权重加入 uncertainty 和 cycle；
4. 每次只改变一组因素并做消融。

## 7. 扩散基线

工程提供条件 DDPM 训练与 DDIM 推理。它用于回答：生成式迭代方法是否在复杂 Fashion 结构上更准确，以及速度代价是多少。需要报告 25/50/100 采样步的质量—延迟曲线。

该实现不是 SpecDiffusion 官方代码逐层复现，论文中应写为“conditional diffusion baseline implemented in our framework”。
