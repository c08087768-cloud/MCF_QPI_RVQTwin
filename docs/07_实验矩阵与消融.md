# 实验矩阵与消融

## 1. 主模型比较

| 编号 | 方法 | 目的 |
|---|---|---|
| B0 | persistence/mean phase | 排除极弱基线 |
| B1 | 原论文风格 ResUNet | 监督回归基线 |
| B2 | ResUNet + uncertainty | 判断不确定度头影响 |
| B3 | conditional diffusion | 生成式质量—速度基线 |
| P0 | spatial-only RVQ | 判断 Fourier 分支贡献 |
| P1 | dual-domain continuous | 判断双域但不量化的贡献 |
| P2 | dual-domain single VQ | 判断 residual VQ 贡献 |
| P3 | full RVQ without twin | 判断经验闭环贡献 |
| P4 | full MCF-RVQTwin | 主模型 |

## 2. 码本消融

- codebook size：64/128/256/512；
- quantizer stages：1/2/3；
- latent channels：32/64/96；
- continuous residual scale：0/0.05/0.15/0.30；
- decoder frozen/unfrozen。

## 3. 损失消融

依次去掉：

- gradient；
- SSIM；
- token CE；
- latent alignment；
- uncertainty NLL；
- cycle L1；
- cycle spectral。

不要只给“全模型最好”；需要显示每项对 ID、跨域和噪声的不同作用。

## 6. 成功标准

在开始实验前预注册内部目标，例如：

- 相比强 ResUNet，fashion 测试 MAE 至少有稳定改善；
- 低样本和噪声条件下相对收益高于 ID 全量条件；
- 三 seed 方向一致；
- risk–coverage 随 coverage 降低而风险下降；
- forward twin 只有在验证和消融同时支持时保留。

这些是研发标准，不应在得到结果前写成论文结论。
