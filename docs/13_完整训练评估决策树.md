# 完整训练与评估决策树

## 1. 数据下载后先做什么

```text
安全解压
  ↓
结构扫描
  ↓
自动配对
  ↓
随机可视化抽查至少 100 对
  ↓
manifest 哈希审计
  ↓
实际数量与论文描述对照
  ↓
HDF5 缓存
```

任何一步失败都不要开始训练。

## 2. 训练顺序

```text
A. mean-phase sanity baseline
B. Phase-RVQ-VAE
C. 评估相位先验重建上限、码本占用和死码
D. 经验 forward twin
E. 在 val 上独立评估 forward twin
F. 原论文风格 ResUNet
G. 强监督 ResUNet
H. 完整 MCF-RVQTwin 或 no-forward-twin 版本
I. 条件扩散基线
```

## 3. forward twin 决策

```text
验证 speckle 相关性/PSNR 较好
  AND
加入 cycle 后主模型 val/test 多 seed 稳定提升
  → 保留

否则
  → 关闭 forward_twin.enabled
  → cycle_l1 = cycle_spectral = 0
  → 将其写成负结果或消融
```

## 4. 主测试协议

### Test-1：官方 mixed test

与原论文可比，但测试样本很少，不能单独作为全部证据。

### Test-2：分域

分别报告 digits 与 fashion。

### Test-3：严格哈希 split

防止完全相同或近似相同标签跨集合。

### Test-4：跨域

```text
digits train/val → fashion test
fashion train/val → digits test
```

训练集和验证集都只能来自源域。

### Test-5：少样本

每域固定 50/200/1000/5000/full；使用同一 val/test。

### Test-6：传感器扰动

clean、噪声、增益、背景、模糊、平移、饱和、坏点。

### Test-7：选择性预测

不确定度从低到高保留 100/90/80/70/50/30%，绘制 risk–coverage。

### Test-8：速度

单次网络报告 batch=1/8/32；扩散报告 25/50/100 DDIM steps。纯模型延迟与端到端延迟分开。

## 5. 仿真数据

- 主训练：不使用；
- 主测试：不使用；
- smoke test：使用程序化小数据；
- 以后得到系统标定后：可增加独立的 sim-to-real 研究，但不能和本项目当前结果混在一起。
