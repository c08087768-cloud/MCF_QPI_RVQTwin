# 论文写作与创新边界

## 1. 可以主张什么

在结果支持时，可以主张：

- 基于公开真实 MCF-QPI 配对数据的相位恢复；
- 双域特征与 Residual VQ 相位先验；
- 数据高效、跨内容域和指定测量扰动鲁棒性；
- 经验测量一致性与不确定度拒识；
- 完整可复现的公开数据协议。

## 2. 不能仅凭该数据主张什么

- 恢复 MCF 内部真实三维折射率；
- 跨任意光纤、任意弯曲和任意波长泛化；
- 活体组织或临床诊断性能；
- 动态通道预测；
- 真实物理补偿或闭环聚焦；
- PINN 或 transmission-matrix 方法，除非新增相应测量和方程约束。

## 3. 与上传的数字孪生波前论文的关系

上传论文用高精度数字孪生生成训练数据，并从单次实验散斑恢复或预测畸变，用于补偿。MCF-QPI 公开数据则已经包含真实成对散斑和二维相位，不需要复制其大规模仿真训练路线。可借鉴的是“把前向测量一致性嵌入训练”的思想，但本项目的经验 forward twin 必须如实称为数据驱动代理，而不是该论文的解析/界面数字孪生复现。

## 4. 推荐论文标题

英文示例：

> Data-Efficient Dual-Domain Residual Vector-Quantized Learning for Uncertainty-Aware Phase Reconstruction Through a Multi-Core Fiber

中文示例：

> 面向多芯光纤散斑相位恢复的双域残差矢量量化与不确定性感知学习

## 5. 推荐结构

1. Introduction：MCF-QPI 速度、泛化和数据效率；
2. Dataset and protocol：公开数据、已知文本矛盾和防泄漏；
3. Method：双域、RVQ、forward twin、不确定度；
4. Experiments：ID、严格 split、跨域、少样本、扰动、延迟；
5. Ablation；
6. Limitations：MNIST/Fashion 标签和单一光学系统；
7. Conclusion。

## 6. 最能提高论文说服力的新增数据

若条件允许，自建少量不在 MNIST/Fashion 分布中的相位：

- USAF/Siemens star；
- Perlin/低通随机连续相位；
- 实测微球或细胞的参考 QPI；
- 不同时间、重新对准后的同一光纤；
- 轻微弯曲、温漂、不同曝光。

即使新增数据只用于最终外部测试，也会显著改善“只在公开简单图形上比较网络”的局限。
