# 审核修复后正式实验执行手册

## 结论先行

旧版 `outputs/research/` 中的 MAE/SSIM 可作为历史诊断，但旧 proposed、phase prior、RVQ 消融必须重训；旧 uncertainty、risk-coverage 和校准结论全部失效。正式结果只写入 `outputs/research_corrected/`。

代码门禁通过不等于论文实验已经完成。正式训练前还必须在服务器生成 HDF5 v2、完成人工近重复核查，并运行 CUDA/AMP smoke。

## 1. 上传修复分支

上传整个修复目录，或在服务器仓库中检出 `audit-remediation` 分支。进入仓库后，确认所有命令均从仓库根目录执行，并使用：

```bash
export PYTHONPATH="$PWD/src:${PYTHONPATH:-}"
```

## 2. 数据门禁

官方 manifest 审计：

```bash
python scripts/audit_manifest.py data/processed/mcf_qpi_manifest.csv \
  --expected-rows 50176 --fail-on-error \
  --output outputs/data_inspection/official_manifest_audit.json
```

创建官方 HDF5 v2（原始相位确认为 8-bit 时使用 `uint8`）：

```bash
python scripts/cache_to_hdf5.py data/processed/mcf_qpi_manifest.csv \
  --output data/processed/official/mcf_qpi_128_v2.h5 \
  --phase-encoding uint8 --size 128 --resize-mode fit_pad \
  --normalization log_mean --dynamic-range 20 --compression lzf
```

严格协议必须先准备人工核查 CSV。字段至少包括：`sample_a,sample_b,phash_hamming,ssim,normalized_mae,decision,review_stratum`。`candidate` 与 `threshold_negative` 各至少 100 对。随后运行：

```bash
python scripts/resplit_manifest.py data/processed/mcf_qpi_manifest.csv \
  --review data/processed/near_duplicate_manual_review.csv \
  --output data/processed/strict/mcf_qpi_manifest_strict.csv

python scripts/audit_manifest.py data/processed/strict/mcf_qpi_manifest_strict.csv \
  --strict-protocol --expected-rows 50176 --fail-on-error \
  --output outputs/data_inspection/strict_manifest_audit.json

python scripts/cache_to_hdf5.py data/processed/strict/mcf_qpi_manifest_strict.csv \
  --output data/processed/strict/mcf_qpi_128_v2.h5 \
  --phase-encoding uint8 --size 128 --resize-mode fit_pad \
  --normalization log_mean --dynamic-range 20 --compression lzf
```

## 3. 服务器 CUDA/AMP 门禁

只用 1 号卡：

```bash
nohup env MCFQPI_DEVICE=cuda:1 bash scripts/run_cuda_amp_smoke.sh \
  > outputs/smoke/cuda_amp.nohup.log 2>&1 &
tail -f outputs/smoke/cuda_amp.nohup.log
```

看到 `CUDA/AMP smoke 通过` 后，才允许正式训练。

## 4. 公平基线与 proposed

公平比较配置：

- `configs/research/controlled_resunet32.yaml`：约 6.26M 参数；
- `configs/research/matched_resunet27.yaml`：约 4.45M 参数；
- `configs/research/proposed_rvqtwin.yaml`：corrected cycle-off；
- `configs/research/proposed_rvqtwin_clean_cycle.yaml`：仅供 clean-cycle 预注册判断。

这些配置统一 batch 32、80 epochs、AdamW、lr `1.5e-4`、weight decay `1e-4`、cosine、min lr `1e-6`、baseline 强度数字增强、固定训练预算，并按 `val_phase_l1` 选择权重。正式比较不启用早停。

每次训练会同时产生：

- `best.pt`：可信完整恢复权重；
- `best.inference.pt`：自包含、安全加载的纯推理权重；
- `reproducibility.json`：Git、环境、manifest/HDF5 指纹；
- `resolved_config.yaml`：最终配置。

评估必须使用 `best.inference.pt`。

## 5. validation 开发、冻结与正式 test

开发阶段只能运行：

```bash
python scripts/dev_pipeline.py --config CONFIG.yaml \
  --checkpoint OUTPUT/best.inference.pt
```

配置确定后，把配置中的 `evaluation.split` 改为 `test`，创建 freeze：

```bash
python scripts/freeze_experiment.py --config CONFIG_FINAL.yaml \
  --checkpoint OUTPUT/best.inference.pt
```

使用输出的 freeze JSON 执行唯一一次正式 test：

```bash
python scripts/final_test_pipeline.py --config CONFIG_FINAL.yaml \
  --checkpoint OUTPUT/best.inference.pt \
  --freeze outputs/freezes/FREEZE_ID.json
```

配置、权重或数据任一指纹改变，final pipeline 会拒绝运行。

## 6. 不确定度校准

先在 validation 拟合温度：

```bash
python scripts/calibrate_uncertainty.py --config CONFIG.yaml \
  --checkpoint OUTPUT/best.inference.pt \
  --output OUTPUT/uncertainty_calibration.json --mc-samples 8
```

test 评估时通过 `--calibration` 加载。脚本会核对模型哈希，禁止把其他模型的温度拿来使用。正式输出包含 mixture NLL、risk-coverage、误差—不确定度 Spearman、ECE 和 68/90/95% 覆盖率。

## 7. RVQ 证据与 clean-cycle 门槛

RVQ 诊断：

```bash
python scripts/evaluate_rvq_evidence.py --config CONFIG.yaml \
  --checkpoint OUTPUT/best.inference.pt \
  --output OUTPUT/rvq_evidence.json
```

它报告连续旁路/离散潜变量范数比、两级码本占用与 perplexity，以及 token shuffle、mean-token 替换后的 MAE。若关键干预造成的性能变化不足 1%，论文不得把性能归因于 RVQ。

clean-cycle 三种子完成后运行：

```bash
python scripts/check_clean_cycle_gate.py \
  --forward-summary FORWARD_VAL/summary.json \
  --cycle-off OFF42.csv OFF123.csv OFF2026.csv \
  --clean-cycle CYCLE42.csv CYCLE123.csv CYCLE2026.csv \
  --output outputs/research_corrected/clean_cycle_gate.json
```

脚本严格执行预注册门槛；未通过时退出码为 2，最终主模型保持 cycle-off。

## 8. 统计

官方和严格协议分别运行层级 bootstrap，不得混合：

```bash
python scripts/hierarchical_bootstrap.py \
  --baseline BASE42.csv BASE123.csv BASE2026.csv \
  --model proposed PROP42.csv PROP123.csv PROP2026.csv \
  --model matched MATCH42.csv MATCH123.csv MATCH2026.csv \
  --metric mae_rad --samples 10000 \
  --output outputs/research_corrected/official/statistics.json
```

输出为同 seed 配对差、seed×sample 层级 bootstrap 置信区间和 Holm 校正后的 p 值。
