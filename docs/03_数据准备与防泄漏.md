# 数据准备与防泄漏

## 1. 下载

```bash
python scripts/download_mcf_qpi.py --datasets all --output-dir data/raw/downloads --hash
```

下载器支持 HTTP Range 断点续传。由于发布页面没有在工程中固化可信校验值，首次下载应保存本机计算的 SHA-256 到实验记录。

## 2. 安全解压

```bash
python scripts/extract_mcf_qpi.py \
  data/raw/downloads/fashion_MCF_QPI_dataset.tar \
  data/raw/downloads/MCF_speckle_digits.tar \
  --output-dir data/raw/extracted
```

解压器拒绝目录穿越、绝对路径和指向目标目录外的符号链接。

## 3. 结构扫描

```bash
python scripts/inspect_raw_dataset.py data/raw/extracted
```

检查：

- 文件扩展名；
- 目录关键词；
- speckle/phase 数量；
- 图像尺寸和位深；
- train/val/test 是否已经在目录中标明。

## 4. 配对

```bash
python scripts/build_manifest.py data/raw/extracted \
  --output data/processed/mcf_qpi_manifest.csv \
  --compute-hashes \
  --assign-unknown-splits
```

自动配对优先使用规范化后的共同索引。只有在确认两个列表严格同序时，才允许：

```bash
--allow-order-pairing
```

使用自然顺序配对后必须至少随机抽查 100 对，换多个随机种子。

## 5. 人工抽查与审计

```bash
python scripts/visualize_pairs.py data/processed/mcf_qpi_manifest.csv --count 20 --seed 42
python scripts/visualize_pairs.py data/processed/mcf_qpi_manifest.csv --count 20 --seed 123
python scripts/audit_manifest.py data/processed/mcf_qpi_manifest.csv --fail-on-error
python scripts/validate_public_dataset.py data/processed/mcf_qpi_manifest.csv
```

核心错误包括：

- 文件缺失；
- sample ID 重复；
- 完全相同的 phase 标签跨 train/val/test；
- speckle 与 phase 索引错位；
- 不同 split 的缓存来源混淆。

## 6. 官方 split 与严格 split

### 官方复现实验

优先保留原目录中的 train/val/test，复现作者协议。

### 严格哈希分组实验

```bash
python scripts/resplit_manifest.py data/processed/mcf_qpi_manifest.csv \
  --output data/processed/mcf_qpi_manifest_strict.csv --seed 42
```

完全相同的相位标签通过 SHA-256 被放到同一 split。严格 split 是额外实验，不替代官方复现。

## 7. HDF5 缓存

```bash
python scripts/cache_to_hdf5.py data/processed/mcf_qpi_manifest.csv \
  --output data/processed/mcf_qpi_128.h5 \
  --size 128 --phase-encoding auto --resize-mode stretch \
  --normalization log_mean --overwrite
```

若实际图像是方形且官方已调整到 128×128，`stretch` 不改变长宽比。若扫描发现非方形，应改用 `fit_pad`，并依靠 `valid_mask` 排除填充区域。

## 8. 为什么不做普通几何增强

固定 MCF 的远场散斑是整个入射相位与纤芯阵列共同作用的全局映射。对散斑和标签同时旋转、翻转或随机裁剪，不一定对应同一物理系统中的合法测量。

允许的增强主要是测量域扰动：

- 相机增益；
- 背景偏置；
- read noise；
- 模糊；
- 小幅相机平移；
- 饱和；
- 坏像素。

增强只作用于 speckle，标签保持不变，用于模拟传感器与配准误差。
