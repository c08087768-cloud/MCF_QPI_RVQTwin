# MCF-QPI 数据集、标签与已知文本矛盾

## 1. 输入和标签

每个样本是一个配对：

```text
speckle：检测端相机记录的 MCF 远场散斑强度
phase：  测量端 SLM 显示并投影到 MCF 端面的原始二维相位
```

论文把 MNIST 与 Fashion-MNIST 图像映射为 `[0, π]` 的单精度相位图；先扩展到 980×980，再补零到 SLM 的 1920×1080。网络使用的散斑和标签最终均调整到 128×128。

## 2. 数据域

- `digits`：手写数字相位结构；
- `fashion`：Fashion-MNIST 服装相位结构。

二者不是自然组织相位。即使 Fashion 比 digits 复杂，也不能等价为生物组织外部验证。

## 3. 论文内部数量不一致

论文不同位置出现了三组略有冲突的描述：

1. 摘要/数据说明：总计 50,176 对；
2. 采集段：29,379 digits + 20,796 fashion = 50,175；
3. split 段：digits 为 26,001/3,300/78，fashion 为 18,001/2,700/96，合计 50,176；
4. 结果段又把 96/78 的 digits/fashion 测试数量写反。

因此工程采取：

- 不根据某一句文字强行移动文件；
- 以实际目录中的 split、文件名和配对关系为主；
- 运行 `validate_public_dataset.py` 记录差异；
- 对配对图做人工抽查；
- 另做严格哈希分组 split 作为稳健性实验。

## 4. 相位单位

HDF5 中：

```text
phase ∈ [0,1]
phase_rad = phase × π
```

训练默认在 `[0,1]` 归一化单位中进行，评估同时输出归一化 MAE 和弧度 MAE。

## 5. 原论文的 fidelity

原论文把二维图像相关系数称为 phase reconstruction fidelity。它不是复光场内积意义上的 optical-field fidelity。本工程输出：

```text
pearson_r
fidelity_2d_correlation
```

两列数值相同，名称并存是为了与原论文对齐且避免概念混淆。
