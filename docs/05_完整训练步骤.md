# 完整训练步骤

## 0. 环境

```bash
bash scripts/setup_env.sh
source .venv/bin/activate
```

显卡驱动不支持默认 CUDA 12.4 wheel 时：

```bash
TORCH_INDEX_URL=https://download.pytorch.org/whl/cu121 bash scripts/setup_env.sh
```

检查：

```bash
python - <<'PY'
import torch
print(torch.__version__)
print(torch.version.cuda)
print(torch.cuda.is_available())
print(torch.cuda.get_device_name(0) if torch.cuda.is_available() else "CPU")
PY
```

## 1. 软件 smoke test

```bash
bash scripts/run_smoke_test.sh
```

该步骤不下载公开数据，通常只需几分钟。失败时先解决环境问题。

## 2. 真实数据准备

```bash
bash scripts/run_data_preparation.sh
```

在开始训练前打开：

```text
outputs/data_inspection/random_pairs.png
outputs/data_inspection/manifest_audit.json
outputs/data_inspection/public_dataset_validation.json
```

## 3. 训练相位 RVQ-VAE

```bash
python scripts/train_phase_rvqvae.py \
  --config configs/research/phase_rvqvae.yaml
```

检查：

- train/val loss 是否同时下降；
- 相位重构是否清楚；
- VQ loss 是否稳定；
- 码本 perplexity 是否不是接近 1；
- validation 不应使用测试数据。

## 4. 训练经验 forward twin

```bash
python scripts/train_forward_twin.py \
  --config configs/research/forward_twin.yaml

python scripts/evaluate_forward_twin.py \
  --config configs/research/forward_twin.yaml \
  --checkpoint outputs/research/forward_twin_seed42/best.pt \
  --split val
```

如果验证图中的 speckle 结构明显错误，或相关系数很低：

```yaml
forward_twin:
  enabled: false
loss:
  cycle_l1: 0
  cycle_spectral: 0
```

## 5. 训练基线

```bash
python scripts/train_inverse.py \
  --config configs/research/baseline_resunet.yaml
```

为了复现原论文训练风格，还提供 `configs/research/paper_style_resunet.yaml`：Adam、batch 64、MAE 主损失和按优化步数衰减学习率。

## 6. 训练主模型

```bash
python scripts/train_inverse.py \
  --config configs/research/proposed_rvqtwin.yaml
```

主配置依赖：

```text
outputs/research/phase_rvqvae_seed42/best.pt
outputs/research/forward_twin_seed42/best.pt
```

## 7. 训练扩散基线

```bash
bash scripts/run_diffusion_baseline.sh
```

扩散训练和测试明显慢于单次前向网络。不要把 25/50/100 步结果混在一起比较延迟。

## 8. 断点续训

```bash
python scripts/train_inverse.py \
  --config configs/research/proposed_rvqtwin.yaml \
  --resume outputs/research/proposed_rvqtwin_seed42/last.pt
```

## 9. 显存不足

依次调整：

1. batch 32 → 16 → 8；
2. 开启 `training.accumulation_steps`；
3. base channels 32 → 24；
4. diffusion batch 16 → 8；
5. 不要降低图像尺寸作为第一选择，因为公开协议是 128×128。

## 10. 三随机种子

```bash
bash scripts/run_three_seeds.sh
```

论文主表报告三个种子的均值和标准差；逐样本 bootstrap CI 不能替代独立训练种子的变异。
