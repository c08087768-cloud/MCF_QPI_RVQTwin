# 代码框架与文件职责

## 1. 顶层目录

```text
MCF_QPI_RVQTwin/
├── configs/
│   ├── research/             # 正式训练配置
│   ├── smoke/                # CPU/GPU 连通性小配置
│   └── ablations/            # 空间/频域/VQ/forward twin 消融
├── data/                     # 原始数据、manifest、HDF5；ZIP 中不含公开数据
├── docs/                     # 中文实验协议
├── outputs/                  # checkpoint、CSV、JSON、图像
├── scripts/                  # 命令行入口与一键流程
├── src/mcfqpi/               # 可复用 Python 包
└── tests/                    # 单元测试
```

## 2. 数据模块

```text
src/mcfqpi/data/download.py
  官方 Figshare 文件元数据和断点续传。

src/mcfqpi/data/archive.py
  防目录穿越的 tar 安全解压。

src/mcfqpi/data/pairing.py
  扫描文件、识别 speckle/phase、按共同索引配对。

src/mcfqpi/data/split.py
  官方 split 继承、未知 split 分配、哈希分组严格划分。

src/mcfqpi/data/audit.py
  重复、缺失、跨集合泄漏和数量异常检查。

src/mcfqpi/data/transforms.py
  speckle 归一化、相位解码、resize、fit-pad、传感器扰动。

src/mcfqpi/data/cache.py
  把图像对预处理并缓存为 HDF5。

src/mcfqpi/data/dataset.py
  CSV/HDF5 Dataset，按 worker 延迟打开 HDF5。
```

## 3. 网络模块

```text
models/resunet.py
  原论文风格与强监督基线。

models/phase_rvqvae.py
  只在 train 相位标签上学习的 Residual-VQ-VAE。

models/rvq.py
  多级 residual vector quantization、token logits、perplexity。

models/dual_domain_rvq_twin.py
  空间域 + Fourier 域编码、门控融合、RVQ 投影、连续残差和不确定度。

models/forward_twin.py
  真实配对学习的经验 phase→speckle 代理。

models/diffusion.py
  条件 DDPM 训练与 DDIM 推理基线。
```

## 4. 训练与评估模块

```text
training/engine.py
  AMP、梯度累积、step/epoch scheduler、早停、checkpoint、TensorBoard。

training/losses.py
  MAE、梯度、SSIM、相关性、Laplace NLL、token/latent、cycle loss。

evaluation/metrics.py
  normalized/radian MAE、RMSE、SSIM、PSNR、相关系数、aligned error。

evaluation/runner.py
  逐样本 CSV、bootstrap CI、分域统计、MC dropout、risk–coverage。

evaluation/robustness.py
  可复现的传感器扰动测试。
```

## 5. 关键命令

```bash
# 数据
bash scripts/run_data_preparation.sh

# 软件连通性
bash scripts/run_smoke_test.sh

# 单随机种子主流程
SEED=42 bash scripts/run_research_pipeline.sh

# 四项核心消融
SEED=42 bash scripts/run_ablations.sh

# 条件扩散
SEED=42 bash scripts/run_diffusion_baseline.sh

# 三随机种子
bash scripts/run_three_seeds.sh
```
